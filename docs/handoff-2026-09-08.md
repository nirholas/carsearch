## 1. Kelley Blue Book is wired (`src/sources/kbb.ts`)

**This is the headline change. KBB is now the largest single source in the index.**

It publishes two things on its search page that nothing else wired here publishes
anywhere.

**`vhrPreview`, a vehicle-history flag set on every record.** Before this,
`owners` sat at 1% coverage and `accidents` at 0%, because that data lives behind
a paid history report everywhere else.

**`pricingHistory`, dated asking prices going back to listing day**, on roughly a
third of records. Everywhere else price history can only be accumulated forward
by observing the same car on two different crawls, so it starts empty and fills
in over weeks. These are seeded into `price_points` on first insert, which is what
the new optional `Listing.priceHistory` field exists for.

It is Cox Automotive, the same parent as Autotrader, and serves images from
`atcimages.kbb.com`. This is largely the inventory Autotrader refuses us, through
a door that is open. **Autotrader is no longer worth attacking.**

### The flags are read literally. Do not "improve" this.

| Flag | Becomes | Must NOT become |
|---|---|---|
| `ONE_OWNER` | `owners = 1` | |
| `NO_ONE_OWNER` | nothing | `owners = 2`. More than one, count unpublished. |
| `NO_ACCIDENTS_REPORTED` | `accidents = 0`, `accidentFree = true` | |
| `ACCIDENTS_REPORTED` | `accidentFree = false` | `accidents = 1`. No count is published. |
| `NO_SALVAGE_TITLE` | nothing | `titleStatus = 'clean'`. Not salvage still leaves rebuilt, flood and lemon open. |
| `FREE_REPORT` | nothing | It is a marketing badge, not a fact about the car. |

Each row is covered by a test in `tests/kbb.test.ts`.

### The trap that will bite you

**An unrecognised make or model slug does not 404.** `/cars-for-sale/used/norfolkkangaroo`
answers **200 with a page of Ford Mustangs and Kia Sorentos**. An adapter that
trusted the URL it requested would file all of them under the requested make,
which is exactly how 159 Mustangs once entered this index labelled `G-Class`.

So the adapter reads each record's own make and drops off-make rows, counted and
logged. A rotted slug reports zero rather than quietly succeeding.

That guard then immediately caught a bug in the crawl script: it turned
`Mercedes-Benz` into `Mercedes Benz`, so the URL was right and the comparison
failed on punctuation, rejecting all 125 correct results with "slug is wrong".
`sameMake()` now compares on alphanumerics only. Both halves are tested.

## 2. The `Transport` type learned its third member

Three transports have existed since Carvana and PCARMARKET were wired, but the
type knew two, so both recorded `transport: 'fetch'` and explained the truth in
prose. `'tls'` is now a real member of the union in `src/core/types.ts`.

## 3. The prober was blind to embedded payloads (`src/probe.ts`)

Two fixes, both of which changed what it reports:

- **It now tests the TLS transport**, but only after the cheaper two have failed,
  and it renders an untested leg as blank rather than as blocked. "We did not test
  this" must never read as "this refused us".
- **It can now see a search response embedded in the page.** Three live sources
  work that way (`__NEXT_DATA__`, `__remixContext`, React Flight). Such a page has
  no JSON-LD and its prices are unformatted integers rather than `$00,000`, so it
  measured as no signal at all, which is indistinguishable from a block.

`npm run probe kbb` now correctly reports `observed: tls`, no drift.

## 4. A make had three spellings (`canonicalMake` in `src/core/normalize.ts`)

`canonicalModel` has existed since the 147-Ferrari incident, but the make itself
was never canonicalised. Copart shouts, most sites title-case, a few lowercase:

```
Porsche 2153   PORSCHE 182   porsche 5
```

That reads as one make and filters as three, so anyone picking the obvious value
silently lost 187 cars. `canonicalMake` fixes spelling only; unlike `parseMake` it
never reads a title, and an unrecognised marque is returned trimmed rather than
dropped. **871 stored rows across 14 shouted spellings were repaired** with
`scripts/canonicalize-values.ts`, which now carries `make` as its first column.

## Other sources on that Google page, measured today

Recorded in `src/sources/registry.ts` so nobody repeats these probes.

- **Exotic Car Trader**: wide open to a plain fetch, no defenses. Two traps. The
  make filter is a **path segment**, so `/cars-for-sale?make=X` is silently ignored
  and returns the generic page with three featured cars. And there is no payload to
  lift: Webflow plus htmx, no JSON-LD, no embedded state, so this is genuine HTML
  parsing. Six McLarens against KBB's 311.
- **J.D. Power**: 403 to a plain fetch on every listings path tried, 404 over TLS,
  meaning the paths guessed do not exist rather than being defended. Syndicates its
  listings anyway, so it duplicates inventory already indexed.
- **OEM certified pre-owned**, tested on McLaren's as representative of the exotic
  tier: `preowned.mclaren.com` resolves only its **UK** region, so it is GBP
  inventory, and the JSON-LD is breadcrumb and organisation markup with nothing
  about the cars. The mainstream brands are the ones worth attacking first, and
  Porsche Finder is explicitly JSON backed.
- **eBay Motors** already reaches the index second-hand through AutoTempest, which
  attributes to the origin site (215 rows). Its documented free Browse API would add
  completed-sale data the passthrough does not carry, and needs only a developer key.

## Environment notes that cost time

- **`gcloud` is not on PATH.** It lives at `/home/codespace/google-cloud-sdk/bin`.
  The database URL is a Secret Manager reference, not a literal:
  `DATABASE_URL="$(gcloud secrets versions access latest --secret=carsearch-database-url)"`.
- **The Codespace recycles and kills background jobs**, taking their `/tmp` logs
  with them. Both crawls died this way. Write crawl logs somewhere that survives, or
  expect to check liveness with `ps` rather than trusting a completion notification.
- **`npx tsx -e` is CommonJS** and rejects top level `await`. Put throwaway probes in
  a file under `scripts/` instead, and delete them after.
- **Never `pkill -f`** in this workspace; it matches the agent's own shell. Kill by
  PID from an anchored `ps` listing.
